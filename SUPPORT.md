# Getting help

Read the [README](README.md) for supported workflows and current limits.
Cave Paper is development source; there is no supported binary release yet.

- Report reproducible defects with the GitHub bug-report template.
- Propose improvements with the feature-request template. Explain the reading
  task, platform and offline requirements before proposing an implementation.
- Report vulnerabilities privately as described in [Security](SECURITY.md).
- Contact the maintainer at info@cave.technology for private project questions.

Include your source commit/app version, operating system, SDK version if building,
steps and the relevant error. Use synthetic PDFs and redact personal paths.
Never attach private PDFs, passwords, library folders, signing keys or credentials.
Check existing issues first. Response times and commercial support are not promised.
